# Gateway Utility — React Console

A modern web-based console for Layer7 API Gateway management tasks, wrapping the existing Graphman automation scripts in a professional Broadcom-themed React UI.

## Navigation

| Page | Description |
|------|-------------|
| **Find Assertions** | Search services & policies for a specific assertion, export matching bundles, optionally replace and re-import |
| **Check Compliance** | Run a multi-assertion audit across all services and policies; expandable detail per assertion |
| **Certificate Management** | View trusted certificates and private keys from the gateway bundle; expiry tracking |

## Architecture

```
GatewayUtility/
├── server.js          # Express API server (port 3002) — wraps Node.js scripts
├── src/
│   ├── App.tsx        # React Router setup
│   ├── components/    # Header, Sidebar, Footer, Layout
│   ├── pages/         # FindAssertions, CheckCompliance, CertificateManagement
│   └── types/         # Shared TypeScript types
├── public/            # Static assets (broadcom.png, favicon)
└── dist/              # Production build output
```

The backend (`server.js`) calls the scripts in `../Find-Assertions/` and exposes REST APIs at `/api/*`.
The Vite dev server proxies `/api/*` to `localhost:3002`.

## Running

### Development (hot reload)

```bash
cd ~/Documents/APIM/Graphman/Scripts/GatewayUtility
npm run dev
```

Opens the React app at **http://localhost:5173** with the API server running on **port 3002**.

### Production

```bash
npm run build    # TypeScript compile + Vite bundle → dist/
npm start        # Serve dist/ + API on port 3002
```

Then open **http://localhost:3002**.

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/health` | Server health check |
| GET | `/api/config` | Read `config.json` |
| POST | `/api/config` | Update `config.json` |
| POST | `/api/search-assertions` | Run `SearchAssertions.js` |
| POST | `/api/export-bundles` | Run `ExportBundles.js` |
| POST | `/api/replace-assertions` | Run `ReplaceAssertions.js` |
| POST | `/api/import-bundles` | Run `ImportBundles.js` |
| GET | `/api/results` | List result JSON files |
| GET | `/api/results/:filename` | Get a specific result |
| GET | `/api/input-data` | Stats from `spFolderSVCFull.json` |
| POST | `/api/compliance-check` | Multi-assertion compliance audit |
| GET | `/api/certificates` | Extract certificate/key data from bundle |
| GET | `/api/bundles` | List generated bundle files |

## Prerequisites

- Node.js v14+
- The `Find-Assertions/` sibling directory with its scripts and `config.json`
- Gateway bundle data at `Find-Assertions/response/spFolderSVCFull.json` (generated by the search workflow)
